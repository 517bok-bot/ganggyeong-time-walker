# 강경 타임워커 (Ganggyeong Time Walker)

> 시간을 걷는 곳, 강경으로! — 오래된 거리에서 만나는 새로운 모험.

강경근대거리(충청남도 논산시 강경읍 옥녀봉로 30-5)를 배경으로 한 **캐릭터 수집형 위치 기반 관광 RPG 웹앱**입니다.
현재 **디자인 리브랜딩 3.1**이 적용되어 있습니다: 동양화 첫 화면, 귀여운 캐릭터, 고지도, 강경 시간 학당 세계관, 근대 의상, 소풍. 1~3단계 기능에 **시간 우체국**과 **소풍 보따리**가 더해졌습니다.
아트 디렉션, 디자인 토큰, 에셋 제작 목록은 [`docs/ART_DIRECTION.md`](docs/ART_DIRECTION.md)를 보세요.

## 🎬 발표용 실행 (가장 쉬운 방법)

1. [nodejs.org](https://nodejs.org)에서 **Node.js LTS**를 설치합니다 (처음 한 번).
2. 압축을 푼 폴더에서 **Windows는 `실행하기.bat`**, **Mac은 `run-mac.command`**를 더블클릭합니다.
   처음 실행할 때만 설치·빌드에 2~4분 걸리고(인터넷 필요), 그다음부터는 몇 초면 열립니다.
3. 브라우저에서 `http://localhost:3000`이 열리면 **화면을 한 번 눌러 음악을 켭니다**. 오른쪽 아래 풍경(종) 버튼으로 볼륨을 조절하거나, 움직임을 줄일 수 있습니다.
4. 시연할 기록이 필요하면 **내 공간 → 🎬 발표용 샘플 기록 불러오기**를 누릅니다. 캐릭터 8종 중 6종, 장소 8곳, 젓갈, 엽서, 배지가 채워진 상태가 됩니다.
5. 탐험 화면의 장소 정보에서 **🧪 현장 도착 시뮬레이션**을 누르면 현장에 가지 않고도 방문 인증과 캐릭터 발견 연출을 보여줄 수 있습니다.

> 발표 전날 한 번 미리 실행해 두세요. 인터넷이 없는 발표장에서도 그다음부터는 동작합니다(웹 글꼴과 실제 지도 타일만 인터넷이 필요).

## 📱 휴대폰으로 함께 플레이

**방법 1. 같은 와이파이 (발표장 추천, 계정 불필요)**
1. 노트북에서 `실행하기.bat`(Mac은 `run-mac.command`)을 실행합니다. Windows 방화벽 창이 뜨면 **허용**을 누르세요.
2. 실행 창에 휴대폰 접속 주소(`http://192.168.x.x:3000`)가 나오고, 브라우저에 **초대 QR 화면**(`/share`)이 자동으로 열립니다.
3. 같은 와이파이의 휴대폰 카메라로 QR을 찍으면 바로 접속됩니다.
4. 장소 인증 QR 인쇄본은 `http://192.168.x.x:3000/admin/qr`에 있습니다(시연용 관리자 미리보기). 휴대폰 기본 카메라로 찍으면 방문 인증이 됩니다.

> http 주소에서는 휴대폰 보안 정책 때문에 GPS와 앱 안 카메라 스캔이 막힙니다. QR은 기본 카메라로 찍으면 되고, ‘현장 도착 시뮬레이션’도 쓸 수 있습니다.

**방법 2. Vercel 공개 주소 (https, 어디서나 접속)**
1. `배포하기.bat`(Mac은 `deploy-mac.command`)을 실행합니다.
2. 처음 한 번은 브라우저가 열리면 Vercel에 로그인합니다(무료, 토큰 입력 불필요).
3. 끝나면 `https://○○.vercel.app` 주소가 나옵니다. 뒤에 `/share`를 붙이면 접속 QR, `/admin/qr`은 장소 QR 인쇄본입니다.
4. https라서 GPS 위치 인증과 앱 안 카메라 스캔까지 모두 동작합니다.

- QR 서명 키는 처음 실행할 때 `.qr-secret` 파일로 만들어지고 계속 같은 값을 씁니다. 인쇄한 QR이 무효가 되지 않도록 이 파일을 지우지 마세요.
- 지금은 각자 휴대폰에 기록이 저장됩니다(로컬 모드). 모두의 기록과 공동 항아리·시간 우체국 편지를 공유하려면 아래 ‘Supabase 연결’을 하세요.
- `ADMIN_DEMO=true`(스크립트가 자동 설정)는 Supabase 없이 관리자 미리보기와 QR 인쇄를 허용합니다. 주소를 아는 누구나 QR 인쇄본을 볼 수 있으니, 정식 운영에서는 Supabase를 연결하고 이 값을 끄세요.

## 빠른 실행 (개발자용, 로컬 모드)

```bash
npm install
npm run dev        # http://localhost:3000
```

Supabase 값을 넣지 않으면 **로컬 모드**로 동작합니다. 기록은 브라우저에 저장되고, 시연용 도구(현장 도착 시뮬레이션, 숙성 빨리감기)가 보입니다.

## Supabase 연결 (서버 모드)

1. [supabase.com](https://supabase.com)에서 프로젝트를 만듭니다.
2. **SQL Editor**에 `supabase/schema.sql` 전체를 붙여 넣고 실행합니다. 여러 번 실행해도 안전하며, Storage 버킷 `content`(공개)와 `postcards`(비공개)도 만들어집니다.
3. **Authentication → Providers**에서 Email(매직 링크)을 켜고, 게스트 시작을 쓰려면 **Anonymous sign-ins**도 켭니다.
4. **Authentication → URL Configuration**의 Redirect URLs에 `https://<도메인>/auth/callback`(개발: `http://localhost:3000/auth/callback`)을 추가합니다.
5. `.env.example`을 `.env.local`로 복사하고 값을 채웁니다.

| 변수 | 위치 | 설명 |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` | 공개 | 둘 다 있으면 서버 모드가 켜집니다 |
| `SUPABASE_SERVICE_ROLE_KEY` | **서버 전용** | 보상 커밋·엽서 저장·관리자 기능 |
| `QR_SECRET` | **서버 전용** | QR 서명 키 (바꾸면 인쇄된 QR이 모두 무효) |
| `ADMIN_EMAILS` | 서버 전용 | 관리자 이메일 목록 (쉼표 구분) |
| `DEMO_TOOLS` | 서버 전용 | `true`면 서버 모드에서도 시연 도구 허용 — **스테이징 전용** |

6. 관리자 계정으로 로그인한 뒤 `/admin`에서 **기본 콘텐츠 DB에 등록**을 누르고, `/admin/locations`에서 장소별 공식 좌표·사진·설명을 입력합니다. 좌표가 등록된 장소부터 GPS 인증이 켜집니다.
7. `/admin/qr`에서 장소별 QR을 인쇄해 현장에 붙입니다.

배포: Vercel 등 Next.js 호스팅에 위 환경변수를 등록합니다. 서버 전용 값에는 `NEXT_PUBLIC_` 접두사를 붙이지 마세요.

## 구조

```
app/                    화면 + API Route
  api/game/{state,action}  서버 게임 상태 조회·행동 처리 (보상 계산·증명 검증·DB 커밋)
  api/postcards, api/account, api/community, api/qr/verify, api/gps/verify
  admin/                관리자 페이지 + 서버 액션 (매 요청 권한 재확인)
  login, auth/callback  로그인
lib/engine.ts           게임 규칙 (순수 함수) — 로컬 모드는 브라우저, 서버 모드는 서버에서 같은 코드 실행
lib/game.tsx            상태 Provider (로컬/서버 모드 전환)
lib/content*.ts(x)      관리자 편집 콘텐츠를 기본 데이터 위에 덮어쓰기
lib/supabase/*          Supabase 클라이언트 (브라우저/서버 세션/Service Role)
lib/data/*              장소·캐릭터·NPC·승인 자료·퀘스트·젓갈·마을 데이터
supabase/schema.sql     DB 스키마 · RLS · 서버 전용 함수 · 버킷
tests/                  엔진 테스트, 테스트용 Supabase 대역 서버
supabase/tests/         스키마·RLS·커밋 함수 테스트
```

## 테스트

```bash
npm test               # 게임 엔진 규칙 17건
```

PostgreSQL이 있으면 스키마·RLS·커밋 함수 테스트도 돌릴 수 있습니다.

```bash
PGHOST=/path/to/socket PGPORT=5432 npm run test:db
```

브라우저 E2E 시나리오(`tests/e2e/`)는 Playwright로 돌립니다. 로컬 모드 흐름, 서버 모드 32건, 시간 우체국 9건이 있습니다.
`tests/mock-supabase.mjs`는 서버 모드 E2E 시험용 Supabase 대역입니다. 로컬 PostgreSQL을 대상으로 Auth·REST·Storage API의 일부만 흉내 내며, 운영에는 사용하지 않습니다.

## 사운드

음원 파일 없이 `lib/audio.ts`가 브라우저에서 국악풍 음악을 실시간 합성합니다. 5음 음계로 지은 자체 창작곡이고, 가야금·대금·장구풍 소리를 씁니다.

| 화면 | BGM |
|---|---|
| 첫 장 | 달빛 강경 (세마치풍 3박) |
| 탐험 | 길 위의 타임워커 |
| 온라인 마을 | 장터 풍경 |
| 젓갈 공방 | 옹기 장단 |
| 도감·여정·화첩·옷장·우체국 | 고서의 밤 |

효과음: 표찰 터치음, 방문 도장, 인연 발견, 고양이 울음, 레벨 업, 여정 완료, 엽전, 항아리 첨벙·보글, 발소리, 책장 넘김, 대화, 셔터, 봉투 열기 등.

## 디자인 시스템 (3.0)

한지 바탕 · 먹선 · 목판 인쇄 질감 · 인장 · 달빛과 안개. 색상 토큰은 hanji #E8D8B8, teal #263D40, sumi #39332F, vermilion #963F38, antique #B58B48, dream #65516F, jade #748A70입니다. 글꼴은 Song Myung(제목), Nanum Myeongjo(표찰), Gowun Dodum(본문), Nanum Pen Script(엽서 손글씨)를 씁니다. 자세한 내용은 `docs/ART_DIRECTION.md`에 있습니다.

## ⚠ 공개 전 확인 사항

- **캐릭터 권리**: 강이·갱이·콩이·베리쥬·대추삼형제·스윗포는 논산 지역 캐릭터입니다. 앱의 SVG는 임시 표현이며, `/admin/characters`에서 공식 원화를 올리고 사용 허가를 '허가 완료'로 바꾸면 자동으로 교체됩니다.
- **위치·역사 정보**: 장소별 공식 좌표·사진·역사는 관리자가 입력해야 합니다. 역사 설명은 '승인' 상태일 때만 공개됩니다.
- **젓갈 미니게임**: 비율·시간·등급은 교육용 게임 수치이며 실제 식품 제조법이 아닙니다.
- 자세한 결정 사항과 출처는 `docs/DECISIONS.md`를 보세요.
